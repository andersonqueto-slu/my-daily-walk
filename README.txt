My Daily Walk — preliminary GitHub Pages PWA
Upload all files in this folder to the ROOT of the GitHub Pages repository.
This is a browser adaptation, not an APK conversion. Includes 370 reviewed devotions, discipleship lessons, and Bible content.
Some Android features (notifications, Android TTS controls, native settings) are not ported.
Important: verify permission to distribute the included NKJV Bible text publicly before uploading to GitHub.
Personal progress is stored in the browser and is not synced with the Android app.
